# 흑과 백 ⚫⚪

더 지니어스에 여러 시즌 나온 두뇌 게임 「흑과 백」. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. 의존성 없는 정적 게임(`index.html` + `logic.js` + `game.js`).

- **규칙**: 각자 **0~8 타일 9장**. 짝수는 검은색, 홀수는 흰색. 한 판에 한 장씩 **엎어서** 내고 둘 다 내면 뒤집어 **큰 수가 이긴다**. 먼저 내는 쪽(선)이 낸 타일의 **색**은 상대도 볼 수 있다(숫자는 모른다). 이긴 쪽이 다음 판의 선이 되고, 같은 수면 비기며(점수 없음) 선은 그대로. 쓴 타일은 다시 못 쓴다. **9판** 중 많이 이긴 쪽이 승리.
- **정보**: 컴퓨터의 남은 타일은 **색만** 보인다(쓴 타일은 숫자가 드러난다). 그래서 쓴 숫자를 세어 남은 숫자를 추리할 수 있다.
- **컴퓨터**: 쉬움(무작위) · 보통(상대가 낼 수 있는 타일 후보로 이길 확률을 계산하고, 확실히 이기면 가장 작은 타일로, 질 판이면 작은 타일을 버림, 약간 흔듦) · 어려움(각 타일마다 남은 판을 끝까지 무작위로 120~160번 두어 보고 이길 확률이 가장 높은 것). 컴퓨터는 숨겨진 정보(내가 엎어 낸 숫자)를 쓰지 않고 **볼 수 있는 정보만** 쓴다(시험으로 확인).
- **조작**: 아래 내 타일을 눌러 고르고 **내기**. PC 는 숫자 키 0~8 으로 고르고 Enter. 소리 M.
- **저장**: 난이도별 전적 `blackwhiteRec`, 로비 표시용 총 승수 `blackwhiteWins`, `blackwhiteMuted`.
- **주의**: 방송의 정확한 규칙은 확인하지 못했다. 홀짝 색(짝수=검정), 비길 때 선이 그대로인 것, 9판 점수제는 일반적으로 알려진 규칙을 따랐다.

시험은 `node --test`(`test/logic.test.js`): 색, 시작 상태, 차례와 타일 한 번만, 판 정산·선 이동·무승부, 색 이벤트, 9판 뒤 승패, 컴퓨터가 늘 가진 타일만 냄, 컴퓨터가 쓰는 정보 후보, 보통·어려움이 무작위를 이기는지(200판), 어려움이 보통을 이기는지, 같은 시드는 같은 판.
